# Angaar Labs

AI-first engineering studio website — Next.js 16, React 19, Tailwind 4, GSAP + Lenis.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

## Structure

- `src/components/hero` — pinned cinematic hero (frame sequence, fire text, offers intro)
- `src/components/impact` — "Our Impact" scroll stories (78+ projects, 12+ countries) and the flame page transitions
- `src/components/Navbar.tsx` — floating ember navbar

Deploys as-is on Vercel (no environment variables required).
